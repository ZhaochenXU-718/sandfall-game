## 1. 最终方向

- 直接采用已确认首页方向稿中的青蓝沙丘图形，不再用 ImageGen 重新解释其轮廓。
- 蓝色稳定底层承托青色自然沙丘；顶部不规则尖峰和向上散开的颗粒表达升级、突破和持续变化。
- 沙丘边缘保留高低错落，不修成几何阶梯、金字塔或整齐积木。
- 图形为严格 2D 正视像素沙；没有 3D 方块、透视、倒角、奖杯、箭头、数字或文字。

## 3. 提取与验证

- 可复现脚本：[extract-art-b06-b07-mode-icons.py](../source/extract-art-b06-b07-mode-icons.py)。
- 以源图深海军蓝背景为基准，只提取亮度明显高于背景的彩砂像素；不会重新排列方块或补画轮廓。
- `256×256` 为标准化工作尺寸，`1024` 使用整数倍最近邻放大，`128/64/48` 使用高质量缩小。
- `48×48` 下仍可识别蓝色底层、青色自然沙丘和顶部向上漂浮的颗粒。

## 4. 与经典模式图标的配对规则

- 两个图标都来自同一张已确认首页方向稿，使用相同 2D 网格尺度、发光强度、透明画布和安全边距。
- 进阶模式是中央向上生长的沙丘；经典模式是稳定包容的 U 形彩砂槽，依靠轮廓而非文字区分。
- 两枚图标都保留少量自然浮粒，不增加白色描边、选中光或卡片边框；这些状态由 UI 层处理。
- 不再将 B06 旧的 3D 四层方块金字塔作为运行时候选；旧稿仅留在 `concepts` 中追溯。

## 5. Cocos 实装建议

- 在模式卡内使用 `128×128` 资源，显示约 `44×44` 设计点。
- 纹理过滤优先检查 `LINEAR` 与 `NEAREST` 两种真机效果：若 `NEAREST` 过硬、浮粒闪烁，则使用 `LINEAR`；不要运行时重复缩放纹理。
- 选中进阶模式时只做一次轻微上浮和亮度脉冲，不持续抖动或旋转。
- 图标内的粒子是静态识别轮廓；首页 Hero 周围的大量悬浮粒子由独立动态层负责。

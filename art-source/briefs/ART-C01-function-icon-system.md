# ART-C01：功能图标统一规范

状态：已完成矢量母版、透明导出和小尺寸检查，并已在 `ART-C08` 接入 Cocos。

视觉方向：C「霓虹像素沙」。

规范预览：[ART-C01 功能图标规范板](../concepts/art-c01-function-icon-system.png)

小尺寸检查：[24 px 实际显示检查](../concepts/art-c01-function-icon-24px-check.png)

## 1. 本次结论

暂停、继续、首页、重开、帮助、音乐、音效、震动和分享统一采用 `4 px` 方格模数构造。图形本体使用直角、阶梯轮廓、方形端点和离散像素节点，与首页模式卡、参数框、金砂按钮和彩沙方粒使用同一种视觉语言。

图标不是对通用圆角线性图标增加霓虹色，而是从轮廓阶段就按像素网格重新设计。SVG 仍保留高清、可缩放和可控的优势；像素语言只约束几何，不把资源降成模糊的低分辨率位图。

所有常规运行时导出都是白色透明蒙版；Cocos 通过 `Sprite.color` 统一着色。音乐、音效和震动另有关闭态图标，使用带透明断口的斜杠，保证关闭状态不只依赖颜色。

## 2. 图标语义

| 图标 | 文件名 | 图形定义 | 主要使用位置 |
|---|---|---|---|
| 暂停 | `pause` | 两根等宽方形实心竖条 | HUD 暂停按钮 |
| 继续 | `resume` | 逐级扩展的向右阶梯箭头 | 暂停态 HUD、暂停弹窗主操作 |
| 首页 | `home` | 阶梯屋顶、方形主体和门洞 | 暂停/Game Over 弹窗 |
| 重开 | `restart` | 分段回转轮廓和像素箭头 | Game Over 主操作、暂停二级操作 |
| 帮助 | `help` | 切角八边形、像素问号和方点 | 首页设置区、暂停弹窗 |
| 音乐 | `music` | 方形双音符和水平横梁 | BGM 设置 |
| 音效 | `sound` | 阶梯扬声器和分段声波 | SFX 设置 |
| 震动 | `haptics` | 方形手机和离散振动块 | 触觉反馈设置 |
| 分享 | `share` | 三个方形节点和阶梯连线 | Game Over 弹窗、平台分享入口 |

音乐、音效和震动同时输出 `music-off`、`sound-off`、`haptics-off`。关闭态斜杠角度、线宽和透明断口完全一致。

## 3. 矢量构造

- 母版视口：`64×64`。
- 基础模数：`4 px`；主体坐标、阶梯转折和装饰方块优先对齐该网格。
- 常规光学安全区：`8～56`；图形中心为 `(32, 32)`。
- 不使用圆形、贝塞尔曲线、圆角端点或圆角连接；需要近似曲线时使用 `4 px` 阶梯轮廓。
- 暂停和继续使用实心控制符号，首页、帮助和手机使用带透明内腔的像素轮廓。
- 关闭态斜杠由每 `4 px` 递进的 `8 px` 方块组成，主体下方使用 `12 px` 阶梯透明断口。
- SVG 根节点使用 `shape-rendering="crispEdges"`，避免整数尺寸导出时出现不必要的软边。
- 图标最小显示尺寸：`24×24`；推荐 HUD 显示尺寸 `24～28`，设置按钮可使用 `28～32`。
- 点击区域与图形尺寸分离：移动端最小点击区域 `44×44` 设计点，不以透明像素决定触控范围。
- 不允许给常规图标添加预烘焙辉光、阴影、渐变或沙粒纹理。

## 4. 状态规范

| 状态 | 图标颜色/变化 | 辅助线索 |
|---|---|---|
| 默认 | `#B4C2DB` | 深色按钮底和 `#4E7398` 交互描边 |
| 按下 | `#EEF3FF`，图形随视觉子节点向下移动 `2` 设计点 | 命中区域固定，不缩放；完整规则见 `ART-C03` |
| 选中/高亮 | `#41CDC3` | 按钮右上角增加 `4×4` 青色方形标记，不能只改变颜色 |
| 禁用 | `#6F8EB1`，整体不透明度 `42%` | 取消辉光、按压位移和反馈 |
| 危险操作 | 图标仍使用主文字色 | 由按钮容器、危险红 `#FF636B` 和确认流程表达，不把“重开”永久画成红色 |

音乐、音效和震动的开/关必须切换到独立的关闭态图标；青色选中态只表达焦点或当前设置，不承担“已开启”的唯一语义。

## 5. 输出文件

矢量源文件位于 `art-source/source/ui-icons/`，每个图标均为自包含 SVG。

透明 PNG 位于 `art-source/exports/ui-icons/`：

- `*-64.png`：ART-C08 的运行时候选母版；白色 RGB、透明背景，供 Cocos 着色。
- `*-32.png`：常规小尺寸检查稿，不建议同时打入运行包。
- 9 个基础语义图标加 3 个关闭态，共 `12` 个 SVG、`24` 个 PNG。

这些文件在 `ART-C01` 阶段不进入 `assets/resources/art/`。`ART-C08` 接入时只复制实际使用的 `64 px` 文件，或在图集方案确认后合并为单张 UI 图集，避免重复纹理。

## 6. Cocos 接入约定

1. `Sprite` 使用 `SizeMode.CUSTOM`，视觉尺寸和按钮 `UITransform` 分开设置。
2. 默认从白色 PNG 通过 `Sprite.color` 映射状态色，不为每种颜色导出新图片。
3. 暂停按钮在游戏运行时显示 `pause`，暂停后原位置可显示 `resume`；弹窗主按钮也可复用 `resume`。
4. Game Over 主操作使用 `restart`，首页返回使用 `home`，平台不支持分享时隐藏 `share` 按钮而不是显示禁用占位。
5. BGM、SFX、震动设置分别在 `music/music-off`、`sound/sound-off`、`haptics/haptics-off` 间切换。
6. 关闭态图标的斜杠已经包含透明断口，不在 Cocos 再叠加第二根斜线。
7. 点击区域继续由现有按钮节点控制，不根据 Sprite 透明区做命中测试。

## 7. 小尺寸验收

- 9 个基础图标在 `24×24` 显示尺寸下轮廓和核心语义可辨。
- 暂停与继续、音乐与音效、首页与重开之间没有近似轮廓混淆。
- 三个关闭态在深色按钮上都能看清像素斜杠和主体，斜杠交叉处由阶梯透明断口分离。
- 图标在小尺寸下仍保留方形端点和阶梯关系，不应被插值成圆润线稿；Cocos 缩放时优先使用整数或半整数设计点。
- 默认图标 `#B4C2DB` 相对主面板 `#0C121F` 保持高对比；交互边界继续使用 `#4E7398`。
- 真机验收需在系统亮度约 `25% / 50% / 100%` 下检查，并覆盖微信与抖音胶囊安全区附近的 HUD 暂停按钮。

## 8. 可复现构建

源文件、PNG 和预览板由 [render-art-c01-ui-icons.cjs](../source/render-art-c01-ui-icons.cjs) 统一生成。脚本只依赖宿主美术工具环境提供的 Sharp，不增加游戏运行依赖。

重新导出时必须保持视口、线宽、命名和关闭态断口一致；若修改单个语义图形，需要重新生成 `24 px` 检查板并重新检查整套轮廓平衡。

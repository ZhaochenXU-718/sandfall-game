# ART-C03：按钮状态规范

状态：已完成四态规范，并已在 `ART-C08` 实装固定命中区与独立视觉子节点。

视觉方向：C「霓虹像素沙」。

规范预览：[ART-C03 按钮状态系统](../concepts/art-c03-button-state-system.png)

真实尺寸检查：[ART-C03 1× 按钮检查](../concepts/art-c03-button-state-1x-check.png)

## 1. 结论

所有按钮共用两级阶梯切角、分段双层边界、顶部短导线、边缘方粒和方形状态标记。状态变化优先通过填充、边界、内容位置和附加标记表达，不添加圆角、连续缩放或弹性动画。

按钮必须同时保留“像素几何”和“像素沙表面”两层特征。深色按钮使用克制的边缘暗网格与稀疏亮粒；金砂按钮使用固定颗粒坐标、宽明暗带和碎边角粒。文字与功能图标中央区域保持干净。

按下态只移动按钮的视觉子节点，`UITransform` 命中区域保持原位。这样既能给出明确的机械按压反馈，也不会因为缩放造成像素边缘模糊、触摸区域跳动或连续点击误判。

## 2. 四种状态

| 状态 | 填充 | 外边界 | 图标/文字 | 非颜色线索 |
|---|---|---|---|---|
| 默认 | `#091728` | `#4E7398`，`2 px` | `#B4C2DB` | 短顶部导线，视觉位置为 `0` |
| 按下 | `#0B1B2C` | `#41CDC3`，`2 px` | `#EEF3FF` | 视觉子节点向下 `2` 设计点，原位置可短暂显示暗色压痕 |
| 选中 | `#102A35` | `#41CDC3`，`2 px` | `#41CDC3` | 顶部导线延长，右上增加 `4×4` 方形标记 |
| 禁用 | `#0C121F` | `#375373`，`1～2 px` | `#6F8EB1` | 整体 `42%` 不透明度，无按压、音效、震动或辉光 |

选中态只用于模式、设置和切换控件。普通动作按钮没有持续选中态；音乐、音效和震动还必须同步使用 ART-C01 的独立关闭态图标，不能只靠青色表示开关值。

## 3. 组件几何

| 类型 | 推荐尺寸 | 切角 | 内容尺寸/字号 |
|---|---:|---:|---|
| 小调节按钮 | `42×30` | `5` | `+ / −` 使用 `18` 号 |
| HUD 图标按钮 | `48×38` | `6` | 图标 `24×24` |
| 弹窗次按钮 | `96×48` 或 `112×48` | `8` | Oxanium/Noto `14～18` |
| 首页金砂主按钮 | `266×60` | `10` | Noto SemiBold `22` |

- 切角使用两级直角阶梯，不使用一条连续斜线模拟切角。
- 外边界 `2 px`，内装饰线 `1 px`，向内缩进 `2 px`；外边允许 `1～2` 处短断点，并使用方形缝线补充节奏。
- 按钮至少保留 `44×44` 触摸区域；`42×30` 小调节按钮必须由父级或额外命中节点扩展到该尺寸。
- 状态装饰只使用整数设计点；Sprite 推荐整数或半整数显示位置。
- 不根据切角透明区域缩小命中范围。

## 4. 像素质感密度

深色按钮：

- `48×38` 图标按钮保留约 `4～7` 个可见方粒，`112×48` 文字按钮保留约 `6～12` 个。
- 方粒大小为 `1～2` 设计点，主要位于边缘 `8～12` 设计点区域，不进入文字和主图标中心。
- 允许极暗的离散网格点，透明度约 `10%～18%`；禁止铺满均匀棋盘格。
- 外边界最多使用两处 `3～6` 设计点短断口，切角转折处不得断开。

金砂主按钮：

- `266×60` 按钮保留约 `48～96` 个 `1～3` 设计点颗粒、两条低透明度宽明暗带和两组角落碎粒。
- 颗粒明暗只使用批准的金黄高光和棕金暗部，不加入彩色噪点。
- 文字绘制在颗粒之上；文字下方不得出现会改变字形轮廓的大颗粒。

同一按钮在默认、按下、选中和禁用之间必须保持颗粒坐标完全不变，只改变颜色、亮度、不透明度和视觉子节点位置。若每次状态变化重新随机颗粒，会产生闪烁并破坏材质连续性。

## 5. 按下反馈

按下时：

1. 命中节点保持原位。
2. `ButtonVisual` 子节点向屏幕下方移动 `2` 设计点。
3. 填充切换到 `#0B1B2C`，内容升亮为 `#EEF3FF`，外边界切换为青色。
4. 不执行缩放、旋转、弹性回弹或模糊阴影。
5. 只有在指针/手指于命中区内成功结束时才执行动作并触发 UI 音效与震动。

触摸移动出命中区或收到 `TOUCH_CANCEL` 时，恢复按下前的默认或选中状态；重新移入时可再次显示按下态。键盘 `Space / Enter` 触发时使用同一状态，最短可见时间建议 `60～90 ms`，避免只闪一帧。

## 6. 选中与禁用

选中态必须同时具备青色边界、延长导线和右上方标，避免只依赖颜色。选中控件被按下时保留右上方标，松开后返回选中态。

禁用态：

- 不注册或不响应动作回调。
- 不播放 UI 音效和震动。
- 不显示按下位移、选中方标或任何辉光。
- 文案仍应说明控件用途；如果功能在当前平台永远不可用，优先隐藏而不是长期显示禁用，例如平台不支持分享时隐藏分享按钮。

## 7. 金砂主按钮

金砂主按钮保持首页既有层级：

- 默认填充 `#FFC44B`，高光边 `#FFDC45 / #FFE770`，文字 `#101827`。
- 按下填充降为 `#E2A62E`，视觉子节点同样下移 `2` 设计点。
- 禁用填充降为 `#705928`，整体约 `52%` 不透明度，文字使用 `#6F8EB1`。
- 默认、按下和禁用共用同一组颗粒坐标与明暗带，只调整颗粒亮度和整体不透明度。
- 主按钮不使用选中态；不要让金色同时表达“当前已选择”。
- 禁止按下时缩放金砂纹理，否则颗粒会发生插值闪烁。

危险红只用于需要明确确认的危险操作容器。重开本身在 Game Over 中属于常规主操作，不应永久绘制成危险红。

## 8. Cocos 状态流

```text
DEFAULT / SELECTED
  └─ TOUCH_START inside → PRESSED（记录 originState）
       ├─ TOUCH_MOVE outside / TOUCH_CANCEL → originState
       └─ TOUCH_END inside → 执行动作 → DEFAULT 或新的 SELECTED

DISABLED → 不进入状态流
```

建议在 `ART-C08` 新增统一视觉控制器或帮助函数，而不是继续让每个按钮独立硬编码颜色：

```text
setButtonVisualState(button, "default" | "pressed" | "selected" | "disabled")
bindButtonStateEvents(button, onActivate)
```

视觉层建议为按钮节点下的固定子节点：

```text
ButtonHitArea          # 固定 UITransform 与事件
└── ButtonVisual       # Graphics、Label、Sprite；按下时仅移动本节点
```

## 9. 验收标准

- 四种状态在正常视觉、低亮度和色觉差异模拟中都具备颜色以外的第二线索。
- 四种状态都保留阶梯切角、分段边界和一致颗粒坐标，不退化成平滑通用矢量按钮。
- 深色按钮的中央文字/图标区无纹理干扰，金砂文字轮廓不被高亮颗粒破坏。
- 按下时触摸区域不移动，不出现缩放模糊或边缘抖动。
- 取消触摸不会误触动作，选中控件取消后恢复选中态。
- 禁用控件不触发回调、声音或震动。
- 小调节按钮实际命中区域不低于 `44×44`。
- 微信与抖音真机连续快速点击时，状态恢复一致，无卡在按下态的问题。
- `1×` 检查图中阶梯角、边框断点和边缘方粒仍可见，且不干扰文字和功能图标。

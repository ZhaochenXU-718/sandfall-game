# ART-B07：经典休闲模式图标

状态：已直接采用首页方向稿中的原始 2D U 形彩砂图形，完成透明母版和 `48×48` 小尺寸检查，等待 `ART-B08` 实装。

透明母版：[经典休闲模式图标 1024](../exports/mode-icons/luosha-mode-classic-1024.png)

小尺寸检查：[经典休闲模式图标 48](../exports/mode-icons/luosha-mode-classic-48.png)

## 1. 最终方向

- 直接采用已确认首页方向稿中的多层 U 形彩砂槽，不再用生成模型重画。
- 蓝、红、青、金彩砂以自然不齐的弧形层叠，表达自由堆积、可调颜色与休闲体验。
- 两侧略高、中部低洼，和进阶模式中央向上生长的轮廓形成直观对照。
- 保留槽内和上方少量零散彩粒；不增加滑杆、齿轮、速度表、数字或文字。

## 3. 提取与验证

- 与 B06 共用可复现脚本：[extract-art-b06-b07-mode-icons.py](../source/extract-art-b06-b07-mode-icons.py)。
- 直接从批准裁图中提取彩砂；不改变各色层次、沙粒位置、U 形宽度和上方浮粒。
- `48×48` 下四层颜色和 U 形低谷仍然清楚，不会误读成进阶沙丘。
- `ART-B08` 中不应再为经典模式叠加复杂的设置符号；颜色数量和下落速度由模式设置区呈现。

## 4. Cocos 实装建议

- 与 B06 使用相同显示盒、锚点、缩放和纹理过滤设置。
- 选中经典模式时可以做一次非常轻的左右回弹，模拟沙粒稳定落入槽内；不持续循环。
- 模式卡描边、选中辉光和禁用态由 UI 层实现，不能烘焙进图标。
- 真机重点检查 `48` 设计点附近的金色内层和顶部独立浮粒是否闪烁。

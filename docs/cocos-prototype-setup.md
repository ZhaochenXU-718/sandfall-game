# Cocos Creator 原型接入

当前仓库已包含 Cocos Creator 3.8.8 的运行组件和可直接构建的 `Game` 场景；以下步骤用于重新创建或调整场景接入。

## 创建最小场景

1. 安装 Cocos Creator 3.8.8。Dashboard 只是版本管理入口，不是运行项目的硬依赖。
2. 使用 Dashboard 导入本仓库根目录，或在 Creator 的项目管理器中直接选择该目录。根目录中的 `package.json` 与 `assets/` 是 Creator 识别项目所需的标志。
3. 等待编辑器完成首次资源导入并生成 `.meta` 文件。
4. 创建一个 2D 场景和 `Canvas`。
5. 可选：在 `Canvas` 下创建带 `Sprite` 的 `SandBoard` 节点。运行时会根据可视区域自动调整棋盘，保持 `12:24` 的宏观比例和正方形单元。
6. 可选：在 `SandBoard` 下创建位置为 `(0, 0)` 的子节点 `PieceOverlay`，添加 `Graphics` 组件；其尺寸会与棋盘同步。
7. 将 `SandfallGameComponent` 挂到 `Canvas` 或单独的控制器节点。
8. 把 `SandBoard` 的 `Sprite` 和 `PieceOverlay` 的 `Graphics` 分别拖入组件属性。
9. 保存场景并设为启动场景，然后执行 Web Mobile 预览。

若没有手动创建或绑定这些节点，`SandfallGameComponent` 会自动生成棋盘、活动块层、状态栏、NEXT 面板和弹窗。竖屏下棋盘会优先占满可用宽度，窄屏时等比缩小；浏览器尺寸或方向变化时会重新计算布局，不拉伸沙粒。

首次进入场景会显示独立全屏首页，棋盘计时和方块生成保持停止。首页当前由代码绘制品牌背景、Logo 区、模式选择、模式参数、本地最高分和开始按钮。进阶模式会升级、加速并在 LV4 解锁第 5 色；经典休闲模式可在开局前选择 `2～5` 种颜色及六档下落速度。点击对应“开始”按钮，或按 `Space` / `Enter`，才会按当前选择创建新局并开始播放。

首页中央的立体彩沙块是无需外部美术资源的 2.5D 占位主视觉，会持续上下漂浮、轻微摇摆和呼吸缩放，点击时触发一次弹跳晃动。后续可以把 `HomeHero` 的 `Graphics` 替换为 Sprite、Spine 动画或 3D 模型节点，同时保留相同的首页动画和点击接口。

## 键盘操作

- `←/A`、`→/D`：水平移动
- `↓/S`：按住软降
- `↑/X`：顺时针旋转
- `Z`：逆时针旋转
- `Space`：硬降
- `P` / `Esc`：暂停或继续
- `R`：重新开始

## 触屏操作

- 在棋盘上点按：顺时针旋转。
- 在棋盘上左右拖动：按拖动距离连续移动活动块。
- 在棋盘上原地长按约 `180 ms`：进入软降，松手或触摸取消时停止。
- 在约 `250 ms` 内快速向下滑动至少 `72` 个设计点并松手：硬降。
- 棋盘只跟踪第一根有效手指；暂停、重开等 UI 控件不会把触摸传给游戏手势。

手势阈值使用 `360 × 800` 设计分辨率中的 UI 点，与手机物理像素密度无关。横拖步距、长按触发时间和硬降距离可在 `SandfallGameComponent` 属性面板中调整。

## 声音与震动反馈

- 第一次键盘或触屏输入后启动循环 BGM，避免触发浏览器自动播放拦截。
- 移动、旋转、落地、硬降、沙化、消除、连锁和 Game Over 使用不同音效；消除使用柔和起音的明亮释放声，连锁叠加上行和弦并随层数提高音量。高频移动音效带冷却限流。
- 消除区域使用高饱和同色核心光和三像素外围辉光；连锁层数越高，亮度、庆祝文字、音效和震动等级越强。
- 落地、硬降、消除、连锁和 Game Over 会请求震动；Web、微信小游戏和抖音小游戏使用各自可用的接口，不支持时不影响游戏。
- 切到后台或暂停游戏会暂停 BGM；返回前台后仍需玩家主动继续游戏。
- 当前音频是仓库内生成的占位素材，可运行 `node tools/generate-audio-assets.mjs` 重新生成，后续可在不修改触发逻辑的情况下替换为正式素材。

## 验证项

- 棋盘按 nearest filtering 放大，沙粒边缘保持清晰。
- 活动块与沙粒显示方向正确，顶部出生、底部堆积。
- 满棋盘时物理 tick、纹理上传和主线程总耗时满足架构预算。
- 进入后台后调用暂停，恢复前台时不自动继续。
- 首次操作后 BGM 正常播放，各领域事件有对应音效；关闭系统震动或不支持震动的设备不报错。

`assets/scripts/cocos/` 依赖编辑器提供的 `cc` 模块；仓库的常规类型检查会读取 Creator 3.8.8 生成的声明，但发布前仍须完成 Creator 构建、移动端浏览器和真机验证。
